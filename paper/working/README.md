[STATUS.md](STATUS.md) records the current state and each accepted merge: pull request, merge account, time, commit and drafting credit. After every merge into main, GitHub Actions rebuilds both documents, regenerates [what changed since version 1.0](CHANGES_SINCE_v1.0.md), and updates the labels and checksums. Contributors edit only `SOURCE/` or the data files; see [CONTRIBUTING.md](https://github.com/matkowsky/payment-fraud/blob/main/CONTRIBUTING.md).

This working draft starts from the published version 1.0 package, which stays unchanged in `paper/v1.0/`. Only changes accepted by merging a pull request are included. The date on the first page of each document is the date of the latest accepted merge.

Read the [current manuscript](MANUSCRIPT.md) ([PDF](MANUSCRIPT.pdf)) and [current supplement](SUPPLEMENT.md) ([PDF](SUPPLEMENT.pdf)), and [what changed since version 1.0](CHANGES_SINCE_v1.0.md). [PROPOSAL.md](PROPOSAL.md) records the first accepted proposal, PR #3; each later change is described in its pull request. [REPRODUCE.md](REPRODUCE.md) explains the build and checks. After each merge, `JOURNAL/` holds the same manuscript in ACM's journal format, as a preprint copy and an anonymous review copy, with `CHECK_REPORT.md` showing that both match the source word for word.

**Author:** Jonathan Matkowsky. Drafting credit for each accepted change is listed in [STATUS.md](STATUS.md) and recorded in its pull request. The version 1.0 text carries its own declaration of AI use. None of this establishes independent human review.

The candidate manifest is [MANIFEST_SHA256.txt](MANIFEST_SHA256.txt). Citation sources, figures and the 19 data tables retain their stated licensing; see [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
