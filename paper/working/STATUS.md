## Accepted merges

None yet. Open pull requests that change `paper/working/` are proposals until merged.

After a pull request that changes `paper/working/` is merged into main, GitHub Actions finds that pull request from the merge commit, records it above, synchronizes these labels, rebuilds both documents and the change record, runs the checks and refreshes the package manifest. A failed run leaves the last committed files intact; the merge record remains the authority for acceptance. A versioned publication is separate. Checks and reviews are recorded in each pull request. This status does not establish independent review, empirical validation or publication.
